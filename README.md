# Teclanauta · Academia espacial de mecanografía

Juego web para aprender a escribir con todos los dedos: lecciones guiadas tecla por tecla, juegos (imagen oculta, lluvia de meteoritos, carrera), medallas y estadísticas de progreso.

**Probalo:** https://teclanauta.vercel.app

- HTML, CSS y JavaScript puro, sin dependencias ni paso de compilación.
- El progreso se guarda en el navegador (localStorage); no se envía ningún dato.
- Pensado para teclado físico (computadora).

## Estructura

```
index.html        Página y navegación
css/styles.css    Estilos
js/core.js        Estado, guardado y utilidades
js/data.js        Lecciones y textos
js/keyboard.js    Teclado en pantalla
js/typer.js       Motor de tipeo
js/screens/       Pantallas (inicio, lecciones, juegos, estadísticas)
```
